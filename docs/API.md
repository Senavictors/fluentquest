# API local — v1

Sessão Better Auth em cookie HttpOnly. Toda consulta de domínio verifica proprietário. Mutação exige Origin igual a `BETTER_AUTH_URL`. Erros retornam `{code,message,retryable,requestId}`. Dados externos e respostas de IA são renderizados como texto, sem HTML executável.

| Operação                                 | Contrato                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /api/bootstrap`                     | Perfil, fontes, sessão ativa, revisões, jornada, orçamento e estado das integrações. `integrations` informa o provedor de texto selecionado (`gemini` ou `openai`), a disponibilidade individual de Gemini, OpenAI e YouTube, `enabled` (`AI_ENABLED`), `keys` (por provedor: `configured`, `origin` `interface` ou `ambiente`, `hint` com os quatro últimos caracteres, `updatedAt`) e `detail` (por provedor de texto: `ready`, `key`, `prices`, `model`, `priceReviewedOn`). A chave em si nunca é devolvida.                                                                                                                                                                                                                                                                                               |
| `PATCH /api/profile`                     | Preferências, limites e atalhos.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `POST /api/diagnostic`                   | Questão inicial de leitura; sem estimativa CEFR.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `GET /api/integrations`                  | Mesmo objeto de `integrations` do bootstrap, sem o restante do estado.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `PUT /api/integrations/:provider`        | Cadastra ou substitui a chave de `gemini`, `openai` ou `youtube`. Corpo `{key}`, de 16 a 300 caracteres em `[A-Za-z0-9._-]`. A chave é cifrada com AES-256-GCM (chave derivada de `BETTER_AUTH_SECRET`) antes de tocar o banco e tem precedência sobre a variável de ambiente correspondente. Nenhuma chamada ao provedor é feita para validar. Devolve o estado das integrações.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `DELETE /api/integrations/:provider`     | Remove a chave cadastrada. A variável de ambiente, se existir, volta a valer. Devolve o estado das integrações.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `POST /api/example`                      | Adiciona o pacote autoral de exemplo uma vez por proprietário.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `POST /api/sources`                      | URL ou texto/legenda, autor, idioma, direitos, consentimento e `transcriptionMode` (`manual` ou `ai`). 202 com sourceId e jobId. A escolha `ai` registra intenção; não dispara inferência.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `POST /api/media`                        | Upload bruto de mídia própria; título, autor e direitos na query. Até 25 MB e 30 min.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `GET /api/sources/:id`                   | Fonte, primeiro lote de segmentos, atividades sem resposta esperada, estado dos jobs e estimativa de transcrição calculada no servidor quando elegível.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `GET /api/sources/:id/segments?cursor=N` | Até 100 segmentos a partir do ordinal.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `POST /api/sources/:id/segments`         | Acrescenta legenda autorizada em nova revisão. `rights` aceita `owned`, `licensed` ou `public_link`. `owned`/`licensed` gravam `origin=user_upload` e `quality_status=user_supplied`. `public_link` só é aceito quando a fonte já foi criada como link público (senão `RIGHTS_MISMATCH`), não altera os direitos da fonte, e grava `origin=public_caption` com `quality_status=ai_unreviewed` — legenda do provedor, não revisada. Rejeita texto vazio (EMPTY_CONTENT); preserva fonte unavailable. Ver ADR-004.                                                                                                                                                                                                                                                                                               |
| `POST /api/sources/:id/transcribe`       | Cria job de transcrição por URL. Exige `{consent:true}`, IA e preços válidos, vídeo público/incorporável com duração conhecida de até 15 min, direitos `public_link`/`owned`/`licensed` e nenhum segmento existente. O job recusa resposta que cubra menos de 80% da duração (`INCOMPLETE_TRANSCRIPT`), resposta que chegou mas reprovou na validação (`INVALID_PROVIDER_OUTPUT`) e linha do tempo acima de 10× a duração, que é erro de unidade (`INVALID_TRANSCRIPT_TIME`); em todos os casos nenhum trecho é salvo, a chamada já feita permanece conciliada e a recusa é registrada em `AI_REJECTED_TRANSCRIPT`. Desvio de estimativa abaixo de 10× é reescalado pela duração real, ancorado no fim do último trecho, com cada trecho aparado dentro do vídeo. Transcrição de vídeo não usa `result_cache`. |
| `PATCH /api/sources/:id`                 | Posição em milissegundos, salva de forma espaçada.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `GET /api/sources/:id/media`             | Mídia privada com Range.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `POST /api/sources/:id/prepare`          | Cria job; exige IA configurada e preços válidos. Recusa fonte indisponível (SOURCE_UNAVAILABLE) ou sem segmentos (NO_TRANSCRIPT).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `DELETE /api/sources/:id`                | Remove fonte e derivados; histórico pessoal permitido permanece.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `GET /api/jobs/:id/events`               | SSE com IDs persistidos e Last-Event-ID; reconexão com estado atual.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `DELETE /api/jobs/:id`                   | Cancela preparo. Uma inferência já enviada pode ser cobrada.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `POST /api/sessions`                     | Inicia/retoma a única sessão ativa.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `PATCH /api/sessions/:id`                | Etapa, contexto ou conclusão.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `POST /api/cards`                        | Expressão, sentido, exemplo, modo e proveniência confirmados pelo aluno.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `GET /api/reviews`                       | Fila devida, total de cartões e próxima revisão.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `POST /api/reviews/:id/answer`           | Nota 1–4 e versão otimista; FSRS e XP atômicos.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `POST /api/reviews/:eventId/undo`        | Desfaz a última revisão do cartão, com evento compensatório de XP.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `POST /api/attempts`                     | Tentativa escrita/oral, ajuda, origem, gravação e reflexão de nova tentativa.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `POST /api/challenges/weekly`            | Tentativa gravada do cenário semanal e reflexão; recompensa única por semana.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `POST /api/recordings/upload-intent`     | Consentimento, tipo, tamanho, duração, retenção; devolve URL assinada por cinco minutos.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `PUT /api/recordings/upload?token=…`     | Arquivo bruto validado, dono da sessão e limite medido de 90s.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `GET /api/recordings`                    | Histórico de gravações e retenção, sem caminho interno.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `GET /api/recordings/:id/audio`          | Áudio autenticado, com suporte a Range.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `PATCH /api/recordings/:id`              | Preservar amostra ou retornar à expiração de sete dias.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `DELETE /api/recordings/:id`             | Exclui objeto privado e registro.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `POST /api/recordings/:id/assess`        | Transcrição e feedback; bloqueado sem IA.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `POST /api/lessons/:id/tutor`            | Pergunta contextual, retorno SSE.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `POST /api/segments/:id/translate`       | Apoio de estudo do trecho, de cache ou por nova chamada limitada. Responde `{support:{translation,point,example,question}}`; para trechos apoiados antes da migração 005, responde `{legacyText}` com o texto corrido antigo.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `GET /api/progress`                      | XP e evidências de prática, sem certificação.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `GET /api/usage`                         | Uso estimado, reservas e limites.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `GET /api/account/export`                | JSON dos dados pessoais, sem segredos ou transcrição integral de terceiros.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `DELETE /api/account`                    | Confirmação EXCLUIR, revogação de sessão e exclusão assíncrona com tombstone.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

Operações de criação de fonte, exemplo, cartão, tentativa, revisão, correção e desafio exigem `Idempotency-Key`. Reutilizar a chave com corpo diferente retorna 409. Respostas concorrentes com versão antiga também retornam 409.

O cliente nunca decide XP, preço, dono ou permissão. Tempos de legenda fornecida são aproximados; texto sem timestamps nunca ganha sincronização inventada.
